# Neon Run

Небольшая аркада на Python и Pygame: управляй квадратом, прыгай через препятствия и собирай рекорды.

## Описание

Игрок управляет персонажем, который автоматически движется вправо. Нужно вовремя прыгать, чтобы не столкнуться с препятствиями. После первой неудачи игра заканчивается, а лучший результат сохраняется между запусками.

В игре есть:

- Главное меню
- Управление прыжком
- Препятствия
- Счёт и лучший рекорд
- Сохранение рекорда в файл
- Звуковые эффекты
- Фоновая музыка
- Пауза во время игры
- Экран проигрыша и возможность начать заново

## Управление

| Действие | Клавиша |
|---|---|
| Прыжок | Пробел |
| Пауза | Esc |
| Начать игру | Пробел |
| Перезапуск после проигрыша | Пробел |
| Выход | Закрыть окно |

## Запуск игры

1. Установи Pygame:

```bash
pip install pygame
```

2. Перейди в папку проекта.
3. Запусти игру

## Настройки

Основные параметры игры находятся в файле `src/settings.py`.

Там можно изменить:

- Название окна
- Размер окна
- Цвета
- Скорость игры
- Громкость звуков
- Громкость музыки
- Путь к файлу с рекордом

## Сохранение рекорда

Лучший результат сохраняется в файл `progress.json`. Он создаётся автоматически при первом сохранении рекорда.
